# Weaverse

**Headless CMS for Shopify Hydrogen.**

![Weaverse website](https://cdn.shopify.com/s/files/1/0838/0052/3057/files/weaverse-website-screenshot-2026-11.png?v=1794295568)

Weaverse gives developers production-ready themes and a visual editor for Hydrogen storefronts on React Router or Next.js. Developers define sections in code; merchants edit content, products, layout and style in Weaverse Studio with a live preview, without breaking your git workflow.

## Get started

```bash
npx @weaverse/cli@latest create --template pilot
```

## Open source

| Repo | Description |
| --- | --- |
| [pilot](https://github.com/Weaverse/pilot) | Flagship Hydrogen theme (React Router) |
| [forward](https://github.com/Weaverse/forward) | Next.js storefront theme |
| [weaverse](https://github.com/Weaverse/weaverse) | Core SDKs for Hydrogen & headless commerce |
| [shopify-hydrogen-skills](https://github.com/Weaverse/shopify-hydrogen-skills) | Agent skills for building Hydrogen storefronts with Claude, Cursor, Copilot |
